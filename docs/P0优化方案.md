## 1. 目标与最终形态

三块改动，围绕一个核心问题：**把看板变成「一眼看清现在在发生什么、并能就地处理」的工作台**。

1. **活跃区 + 未置顶待审批卡板内审批**：不必先置顶也能在看板里直接审批；顶部固定栏放你手动固定的会话，其余按「活跃/全部」两种视图呈现。
2. **入口状态提示（颜色制）**：侧栏图标与「返回看板」按钮用颜色表达「有没有待处理」，不用数字。
3. **板内「活跃｜全部」视图切换**：把「只看活跃 / 看全部」从设置页搬到板上，双向可切。

看板最终结构：

    看板
    ├─ header：标题 + [活跃 | 全部] 两个切换按钮 + 图例
    └─ 滚动区
       ├─ 顶部固定栏（Pinned Bar）—— 始终显示，只放「已固定」会话
       └─ 主区（随模式切换）
          ├─ 活跃（默认）：活跃集合(时间窗口) − 已固定，平铺、按状态排序
          └─ 全部：全部未归档 − 已固定，按工作区分组、可折叠

## 3. 状态模型（三类）

| 分类 | 判定信号（client.js） | 说明 |
|------|----------------------|------|
| 待审批 | status.pendingInteraction 存在 | kind 属于 approval / plan-review / question |
| 在运行 | status.running === true（无 pending） | 含 hasRunningChild 子代理在跑 |
| 已完成 | 其余 | 不区分未查看/已查看，统一绿色 |

- 来源函数复用：pendingKindOf（L821）、hasRunningChild（L828）、deriveCardStatus（L840）。
- 视觉：状态一律用**卡片底色**（运行中=雾蓝、待审批=警示黄、已完成=绿）；底部小标签保留。

## 4. 看板结构、视图与分区

去重铁律：**手动置顶优先**——固定栏独享已固定会话，活跃/全部都不再重复出现它们。

| 区域/视图 | 包含哪些卡 | 组织方式 | 排序 |
|-----------|-----------|----------|------|
| 顶部固定栏 | 仅 pinnedSessionIds | 网格 | registry 顺序（尊重手动） |
| 活跃（默认） | 活跃集合 − 已固定；活跃集合 = 待审批 ∪ 在运行 ∪ (已完成且 updatedAt 在窗口内) | 平铺 | 待审批(0) → 在运行(1) → 已完成(2)；同级 updatedAt 降序 |
| 全部 | 全部未归档 − 已固定（含三类） | 按工作区分组，可折叠 | 组内按 updatedAt 降序（默认假设，可调） |

## 5. 活跃判定、窗口、排序、清退

    // 偏好键
    const SHOW_ALL_KEY       = 'session-board:show-all-cards'        // 视图模式：活跃=false / 全部=true
    const ACTIVE_WINDOW_KEY  = 'session-board:active-window-minutes' // '30' | '60' | '0'(一直显示)，默认 '60'
    const ACTIVE_DISMISS_KEY = 'session-board:active-dismissed'      // { [id]: dismissedAtUpdatedAt }
    const COLLAPSED_WS_KEY   = 'session-board:collapsed-workspaces'  // [workspaceId...]

    // 活跃判定（纯派生，不写官方 pin 注册表）
    function isActiveCard(card, windowMs, now, dismissed) {
      if (card.status.key === 'running' || card.status.key === 'pending') return true    // 在跑/等你，永远活跃
      if (windowMs !== 0 && now - (card.updatedAt || 0) > windowMs * 60000) return false  // done 超出窗口 → 退场
      const d = dismissed[card.id]
      if (d !== undefined && d >= (card.updatedAt || 0)) return false                    // 手动 × 收掉，直到再次更新
      return true
    }

    const STATUS_RANK = { pending: 0, running: 1, done: 2 }
    const byStatusThenRecency = (a, b) =>
      (STATUS_RANK[a.status.key] - STATUS_RANK[b.status.key]) || (b.updatedAt - a.updatedAt)

    // 分区（去重：手动置顶优先）
    const pinnedIds   = new Set(pinnedCards.map(c => c.id))
    const activeCards = cards.filter(c => !pinnedIds.has(c.id) && isActiveCard(c, windowMs, now, dismissed))
                            .sort(byStatusThenRecency)
    const allCards    = cards.filter(c => !pinnedIds.has(c.id))   // 全部视图用，再按 workspace 分组

- **窗口**：默认 1 小时；只作用于「已完成」，运行中/待审批恒为活跃。
- **清退**：已完成卡在活跃视图可点「×」从活跃区移除（写 dismiss 集，标记 >= updatedAt 时隐藏，会话再次更新后自动失效可重现）；运行中/待审批不给 ×（移掉会回弹）。
- 「一直显示」(window=0) 时已完成不自动离开，靠「×」清退。

## 7. 入口状态提示（侧栏图标 + 返回看板按钮，颜色制）

    // 与看板同口径：排除 blank / subagent / archived
    function computeEntrySignal(list, statusMap, workspaceState) {
      const result = { hasPending: false, hasRunning: false }
      if (!list || list.phase !== 'ready' || !list.ids) return result
      const archived = new Set((workspaceState && workspaceState.archivedSessionIds) || [])
      for (const id of list.ids) {
        const summary = list.byId && list.byId[id]
        if (!summary || summary.blank || summary.origin === 'subagent' || archived.has(id)) continue
        const raw = statusMap && typeof statusMap.get === 'function' ? statusMap.get(id) : undefined
        const status = deriveCardStatus(summary, raw, statusMap, list)
        if (status.key === 'pending') result.hasPending = true
        else if (status.key === 'running') result.hasRunning = true
        if (result.hasPending && result.hasRunning) break
      }
      return result
    }

    function entryTone(signal) {
      if (signal.hasPending) return 'var(--dsw-alias-state-warn-primary)' // 待审批 → 警示黄
      if (signal.hasRunning) return 'var(--dsb-running-accent)'           // 运行中 → 雾蓝
      return null                                                         // 无 → 原色
    }

- 颜色优先级：**有待审批（黄）> 仅运行中（蓝）> 无（原色）**。
- BoardIcon（L1122）：顶部无条件调用 props.useSessions / useSessionStatus / useWorkspaces，tone = props.active ? null : entryTone(...)，给 svg 设内联 style 的 color（currentColor 取该色）。
- BackToBoardButton（L1454）：同上，按钮设内联 style 的 color，不带数字。
- 技术坑：--dsb-running-accent 目前只在 .dsb-page 作用域，需提升为全局：

      :root { --dsb-running-accent: #3e7ea8; }
      body[data-ds-dark-theme] { --dsb-running-accent: #7fb7d9; }

- 零新依赖：上述 hook 均在 standardProps 中（本机 0.2.1-rc.5 契约已核实），无需改 package.json / inject；仍用自己的 id 注册，replaceRisk=none。

## 13. 边界与风险

1. 抽屉改 inline 后，expandedCard 必须跨视图/分组查找，否则展开找不到卡片。
2. 去重铁律：固定栏独享已固定；活跃/全部均排除 pinned，否则重复。
3. window=0（一直显示）时已完成只能靠「×」清退；× 只给已完成卡。
4. SHOW_ALL_KEY 语义从「下方显示全部」变为「视图模式」，旧偏好值仍可用（0/1 兼容）。
5. 手动 pin/unpin 仍走 togglePin → 官方 pinSession/unpinSession，不写派生逻辑。
6. 定时器务必在 useEffect 清理（clearInterval），避免热重载残留。
7. 入口组件 hooks 必须无条件调用；props.active 只影响是否上色。
8. 「全部」视图组内排序默认为 updatedAt 降序（如需改为状态优先可后续调）。

## 14. 验收标准

- [ ] 顶部固定栏只显示已固定会话，且活跃/全部视图不再重复出现它们。
- [ ] 未置顶的待审批卡：在「活跃」「全部」两种视图下都能首点展开抽屉、板内「允许一次/拒绝」或选项作答。
- [ ] 活跃视图：只显示时间窗口内的待审批/在运行/已完成，顺序 待审批>在运行>已完成，越早完成越靠后；超过窗口的已完成自动离开（60s 内生效）。
- [ ] 全部视图：全部未归档(非固定)按工作区分组，可折叠、默认展开、刷新后记忆。
- [ ] 头部「活跃｜全部」两按钮可切换、选中态清晰、默认活跃、刷新保持、跨标签同步。
- [ ] 设置页无「显示全部卡片」开关，有「活跃窗口」下拉（30/60/一直）并持久化；板底无「显示全部」按钮。
- [ ] 侧栏图标：有待审批=警示黄、仅运行中=雾蓝、无=原色；面板选中时不染色。
- [ ] 返回看板按钮随信号变色，不带数字。
- [ ] 状态仅靠卡片底色 + 底部小标签表达；已完成不区分未查看/已查看。
- [ ] 全程纯客户端：未写官方 pin 注册表、未改 Host/DB。

## 15. 不做项（明确砍掉）

- 图例点击筛选（维持现状）
- 审批队列（答完只关闭、下一个手动点、无翻页、无数字）
- 侧栏/返回按钮上的数字计数
- 自动归档 / 删除已完成会话（清退仅取消置顶或从活跃区移除）
