# P0-② 方案 · 板内视图切换（活跃｜全部）

> ⚠️ 已合并入 docs/P0优化方案.md，本文仅作历史参考。

> 状态：**已定稿，待实现**（2026-11-03 讨论确认）
> 约束：纯客户端；不改 Host/DB；不写官方 pin 注册表。

---

## 1. 最终视图结构

```text
看板
├─ header：标题 + [活跃 | 全部] 两个切换按钮 + 图例
└─ 滚动区
   ├─ 顶部固定栏（Pinned Bar）          —— 始终显示，只放「已固定」会话
   └─ 主区（随模式切换）
      ├─ 活跃（默认）: 活跃集合(时间窗口) − 已固定，平铺、按状态排序
      └─ 全部        : (全部未归档 − 已固定)，按工作区分组、可折叠
```

状态只有三类：**待审批 / 在运行 / 已完成**（已完成**不再**区分未查看/已查看）。

## 2. 决策记录

| # | 决策 |
|---|------|
| 1 | 头部两个按钮「活跃」「全部」，点击切换 |
| 2 | 排序：**待审批 > 在运行 > 已完成**；越早完成越靠后 |
| 3 | 已完成**不作区分**（不拆未查看/已查看，统一绿色） |
| 4 | 活跃 = **时间窗口内的集合 − 已固定**（沿用 P0 活跃窗口，默认 1h 可设置） |
| 5 | 全部 = 按工作区分组，**可折叠、默认展开、折叠状态记忆**，**排除已固定** |
| 6 | 顶部固定栏只显示已固定会话（活跃/全部都要减去固定，避免重复） |
| 7 | 删除设置页的「显示全部卡片」开关 |

## 3. 各视图内容

| 视图 | 包含哪些卡 | 组织方式 | 排序 |
|------|-----------|----------|------|
| 顶部固定栏 | 仅 pinnedSessionIds | 单行/网格 | registry 顺序（尊重手动） |
| 活跃（默认） | 活跃集合 − 已固定；活跃集合 = 待审批 ∪ 在运行 ∪ (已完成且 updatedAt 在窗口内) | 平铺 | 待审批(0) → 在运行(1) → 已完成(2)；同级 updatedAt 降序 |
| 全部 | 全部未归档 − 已固定（含三种状态） | 按工作区分组，可折叠 | 组内按 updatedAt 降序（默认假设，可调） |

- 活跃窗口沿用已定稿的 `isActiveCard`：`running / pending` 恒活跃；`done` 仅窗口内活跃。

## 4. 交互与样式

- 头部右侧、图例前放两个药丸按钮「活跃」「全部」；选中态高亮（brand / business-tertiary），未选 ghost。
- 点击切换 + 持久化（沿用 `SHOW_ALL_KEY`：活跃=false、全部=true），跨标签 `storage` 同步。
- 默认「活跃」。
- 工作区折叠：组头可点；折叠状态存 `session-board:collapsed-workspaces`（数组，按 workspaceId 记忆），**默认展开**。
- 与 ③ 图例筛选正交（本控件管视图/范围，③ 管状态过滤）。

## 7. 验收标准

- [ ] 头部「活跃」「全部」两按钮，点击切换，选中态清晰，默认活跃。
- [ ] 顶部固定栏只出现已固定会话；活跃/全部都不重复出现它们。
- [ ] 活跃：只显示时间窗口内的待审批/在运行/已完成，按 待审批>在运行>已完成 排，越早完成越靠后。
- [ ] 全部：全部未归档(非固定)按工作区分组，工作区可折叠、默认展开、刷新后记忆。
- [ ] 设置页无「显示全部卡片」开关；板底无「显示全部」按钮。
- [ ] 未置顶待审批卡在「活跃」和「全部」两种视图下都能板内展开审批。
- [ ] 纯客户端，未写官方 pin 注册表、未改 Host/DB。

## 8. 与「活跃区方案」的关系

本方案确定了看板**最终视图结构**，取代 `docs/P0-active-board-plan.md` §5 的「置顶 + 正在处理 + 下方折叠」三段式：
- 原「正在处理」段 → 现为「活跃」视图内容；
- 原「下方工作区(已退场)」→ 现为「全部」视图（且包含全部非固定会话，不只是 done）；
- 原「已收起 N 个 · 显示全部」→ 由头部「活跃｜全部」取代。
活跃判定、窗口、dismiss ×、排序等核心逻辑不变。
